Security and voter settings

Public voting is enabled. The site uses a browser-stored anonymous voter token to discourage repeat votes on the same browser. This is not identity verification: a person can bypass it by clearing browser storage or using another browser/device.

Because the existing tables permit public reads for compatibility, hiding results here hides the page display but does not make raw result data private. Do not use this tool for legally binding or government elections.
